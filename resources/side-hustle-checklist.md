# 副业起步验证清单

Kingslou · 从一个具体问题开始

## 1. 找到需求

- [ ] 写出你希望帮助的具体人群。
- [ ] 记录他们遇到的问题、发生场景和现有解决方式。
- [ ] 与至少一位潜在使用者交流，确认问题真实存在。
- [ ] 区分“觉得不错”和“愿意投入时间或金钱”。

## 2. 设计最小尝试

- [ ] 用一句话说明这次交付能带来什么。
- [ ] 列出交付内容、格式、时间与修改范围。
- [ ] 明确本次不提供的内容。
- [ ] 选择一个能在一周内完成的小版本。

## 3. 设定投入边界

- [ ] 每周可投入时间：____ 小时。
- [ ] 本轮预算上限：____ 元。
- [ ] 验证结束日期：____。
- [ ] 继续、调整或停止的判断依据：____。

## 4. 记录真实反馈

- [ ] 接触的人数与渠道：____。
- [ ] 对方最在意的问题：____。
- [ ] 愿意尝试或付费的反馈：____。
- [ ] 实际花费的时间与费用：____。

## 5. 完成一次复盘

- [ ] 本轮已经完成的交付：____。
- [ ] 下次可以复用的资料：____。
- [ ] 可以删除或简化的步骤：____。
- [ ] 下一步只做的一件事：____。

这份清单用于整理行动，不构成收益承诺。按自己的实际条件调整节奏。
